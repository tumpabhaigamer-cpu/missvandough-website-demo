# Miss Van Dough website demo

Open `index.html` in a browser to view the responsive, single-page website concept. The demo includes interactive category filters, product detail popups, mobile navigation, subtle 3D hover effects, and direct links to the Instagram profile and order link shown there.

The profile details, product names, captions, and photographs were gathered from the public `@missvandough` Instagram profile and its visible posts. Product availability and prices are intentionally not shown because the inspected Instagram content did not establish current stock or pricing. The logo image is the profile's own mark; display fonts use local system fonts so the page does not depend on external font services.
